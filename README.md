
# CyberShield 🛡️

A cybersecurity monitoring and learning platform built with HTML, CSS and JavaScript.

## Features

- Security operations dashboard with simulated threat activity.
- Incident management with create, edit, search, filter, update and delete actions.
- Incident priority and status tracking.
- CSV export for incident records.
- Phishing email detector using rule-based text analysis.
- Password strength checker with local evaluation and improvement tips.
- Interactive cybersecurity quiz with explanations and saved progress.
- Responsive dark navy and purple interface.
- Browser-based data persistence using localStorage.

## Technology Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser localStorage
- SVG charts

## Getting Started

1. Download or clone this repository.
2. Open the CyberShield folder in Visual Studio 2022.
3. Open `index.html` in a modern web browser.
4. Explore the dashboard, analyse a sample email, test a password, complete the quiz and manage incidents.

No Python installation, package manager or build process is required.

## Data and Privacy

Incident records and quiz progress are stored locally in the browser. They are not shared between devices and are not backed by a server.

The password checker evaluates the entered password locally and does not intentionally save or transmit it. Avoid entering real passwords into demonstration tools.

## Security Disclaimer

CyberShield is an educational portfolio project. Dashboard activity is simulated, and the phishing detector uses simple heuristics. The application does not perform real-time monitoring, connect to threat intelligence services or guarantee the detection of malicious messages.

Do not use this demonstration as a substitute for production security controls.
